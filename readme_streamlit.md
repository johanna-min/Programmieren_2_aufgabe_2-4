This repository is used for exercise 2 - 4 of the programming lecture. This project is done by Johanna Helfer and Luisa Kneppel. 

In der 4. Aufgabe haben wir unsere bisherigen Codes mit neuen Modulen erweitert, um eine übersichtliche und verständliche App zu gestalten. 
Zuerst haben wir die Module person.py und ekgdata.py entwickelt. Person.py lädt Personendaten aus der Datei data/person_db.json und erstellt daraus Objekte der Klasse Person. Jedes Objekt der Klasse enthält die personenbezogenen Informationen. In der Funktion get_person_data() werden alle Personen als Liste zurückgegeben und über get_person_object_by_full_name() anhand von "Nachname, Vorname" gesucht. Ekgdata lädt EKG-Messdaten und speichert sie in einem DataFrame. Die Klasse EKGdata instanziiert einen EKG-Test (mit der ID) inload_by_id und sucht mit der Methode find_peaks, Peaks in den EKG-Daten und berechnet mit estimate_hr daraus die durchschnittliche Herzfrequenz. Mit plot_time_series() wird die EKG-Zeitreihe daraufhin dargestellt. Dabei werden die Messwerte über der Zeit geplottet und die erkannten Peaks werden zusätzlich als rote Punkte markiert, damit die Ausschläge im EKG-Signal direkt sichtbar sind.
Die Grundstruktur haben wir aus dem bereits bestehendem Hauptmodul übernommen. Zu Beginn haben wir die benötigten Funktionen aus unseren Nebenmodulen importiert. 
Als erstes haben wir teile des Codes so angepasst, dass direkt auf die Klasse Person zugegriffen werden kann und nicht mehr über das read_data.  Anschließend haben wir eine If – Else Bedingung eingeführt, um sicherzustellen, dass für die ausgewählte Person überhaupt EKG-Tests in der Datenbank vorliegen (len(person.ekg_tests) > 0). Ist dies nicht der Fall, wird durch das Else eine Warnung auf der Benutzeroberfläche ausgegeben. Innerhalb der if Bedingung haben wir ein neues Dropdown Fenster eingebaut, wodurch man die verschiedenen Tests anhand des Datums auswählen kann. Über den Index kann man auf die einzelnen Tests zugreifen und die Ergebnisse in einem Diagramm darstellen. Für die Darstellung haben wir uns dazu entschlossen mit einem vorgegebenen Threshold von 340 zu arbeiten. Dieser Schwellenwert wird an find_peaks(threshold) übergeben, um die exakte Herzfrequenz zu ermitteln und den Plot zu generieren.
Um die Streamlit App zu starten, gibt man in die Kommandozeile „streamlit run main.py“ ein.
